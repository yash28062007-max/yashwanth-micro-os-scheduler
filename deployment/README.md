# 🚀 Yashwanth Micro-OS: Dynamic Quantum Scheduler Simulator

This interactive web application is the educational companion simulator for the **Yashwanth Micro-OS** Operating Systems Engineering Project (CA-6).

> ⚠️ **ACADEMIC COMPANION NOTICE:** This is a zero-dependency client-side simulator hosted on a Hugging Face Static Space. The genuine operating system kernel is written in bare-metal **Rust (`no_std`, `no_main`, x86_64)** with Limine bootloader protocol and QEMU hardware emulation.

## 🌟 Interactive Features
- **Algorithm Comparison:** Dynamic Quantum Round Robin (DQ-RR) vs. Static Round Robin (RR).
- **Dynamic Quantum Adaptation:** Mathematical modeling of queue depth scaling, behavioral yielding adjustment, and priority weighting.
- **Interactive Gantt Chart:** High-resolution scheduling timeline with color-coded task lifecycles, voluntary yields, and quantum expirations.
- **Performance Analytics:** Real-time computation of average waiting time, turnaround time, context switch overhead, and Jain's Fairness Index.
- **Pure Static Architecture:** Instantaneous client-side execution with zero cold-start delay, 100% availability, and no backend dependencies.
